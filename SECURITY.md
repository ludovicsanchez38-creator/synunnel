# Signaler une faille

Merci de ne pas ouvrir de ticket public pour une vulnérabilité. Utilisez le signalement privé du dépôt (onglet **Security**, bouton **Report a vulnerability**), en décrivant la version concernée, le scénario et son impact.

Synunnel est en version alpha : les limites déjà connues sont listées dans [docs/SECURITE.md](docs/SECURITE.md#limites-connues-de-la-v03-alpha). Un signalement qui les précise ou montre qu'elles vont plus loin que décrit reste le bienvenu.
